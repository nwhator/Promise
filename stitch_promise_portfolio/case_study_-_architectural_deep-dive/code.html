01.

The Challenge

The Federal Ministry of Education faced a critical data integrity crisis. Academic records were fragmented across 140+ institutions, leading to widespread duplication and unchecked plagiarism. The legacy system, built on a monolithic PHP architecture, choked under the load of concurrent submissions during examination periods.

Core Problem Statement

"How do we ingest, normalize, and cross-reference 50 million text records in near real-time with sub-200ms latency, while ensuring 99.9% availability during peak academic seasons?"

Beyond performance, data privacy was paramount. We needed a solution that could detect similarities without exposing the raw intellectual property of student theses to unauthorized personnel.

02.

The Architecture

We transitioned from a monolith to an event-driven microservices architecture. This decoupled the ingestion layer from the heavy compute processing required for text analysis.

Live

input Ingestion Layer

API Gateway + Lambda handles initial validation and pushes payloads to SQS.

memory Compute Engine

Rust workers consume queues to perform heavy Locality Sensitive Hashing (LSH).

database Storage

PostgreSQL for metadata, S3 for blobs, and Pinecone for vector similarity search.

03.

The Solution

The breakthrough came by rewriting the comparison engine in Rust. Python was excellent for the API layer, but the GIL (Global Interpreter Lock) became a bottleneck for CPU-bound hashing tasks.

src/hashing/minhash.rs 
use std::collections::HashSet;

/// Generates MinHash signatures for document similarity
pub fn compute_signature(shingles: &HashSet<u32>, num_hashes: usize) -> Vec<u32> {
    let mut signature = vec![u32::MAX; num_hashes];

    for shingle in shingles {
        for i in 0..num_hashes {
            let hash = hash_fn(*shingle, i);
            if hash < signature[i] {
                signature[i] = hash;
            }
        }
    }
    signature
}

// By switching to Rust for this specific hot path, we reduced memory overhead by 70% compared to the Python implementation.
