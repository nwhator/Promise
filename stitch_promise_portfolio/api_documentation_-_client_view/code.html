Get User Profile

Retrieves the public profile information for the authenticated user. This endpoint returns the user's ID, email, role, and current project assignments.

Stable
GET
https://api.nwhator.com/v1/users/me

security Authorizations

Header Type
Authorization string
Required. The Bearer token received from login. Bearer <token>

Query Parameters

Parameter Type Description
include_projects
 boolean Optional. Whether to return the full list of projects assigned to the user. Default is false.
format
 string Optional. Response format. Values: json, xml.

Response Attributes

id string (uuid)

Unique identifier for the user.

email string

The user's registered email address.

role enum

One of: admin, editor, viewer.

Example Request

"data": {
  "id": "usr_8j29f8a8-44b1",
  "email": "sarah.e@client.com",
  "full_name": "Sarah Engineer",
  "role": "admin",
  "created_at": "2023-10-15T08:30:00Z",
  "is_active": true,
  "projects": [
    {
      "id": "prj_9982",
      "name": "Alpha Migration",
      "status": "in_progress"
    },
    {
      "id": "prj_1102",
      "name": "Beta API Integration",
      "status": "planning"
    }
  ],
  "rate_limit": {
      "remaining": 985,
      "total": 1000,
      "reset_in_seconds": 45
  }
}
24ms latency
application/json
info

Rate Limiting

Your client tier allows for 1,000 requests per minute. Headers X-RateLimit-Remaining are included in every response.
